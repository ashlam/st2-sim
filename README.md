# 尖塔之下 · 杀戮尖塔 2 简化复刻（移动端网页版）

以《Slay the Spire 2》(v0.111.0) 为蓝本的个人练习项目：**文字为主 + 简单动画**，竖屏手机 UI，
玩法与数值尽量按原作还原。纯前端（原生 ES Module，无构建、无框架），可在 PC 浏览器直接玩，
也可以装到安卓手机上全屏运行。

> 与 Mega Crit 无关，仅供个人学习与娱乐，请勿发布或商用。

## 一、两个参考仓库的对比

| | [hongyipan152/STS2SourceCode](https://github.com/hongyipan152/STS2SourceCode) | [iRyougi/sts2-sim](https://github.com/iRyougi/sts2-sim) |
|---|---|---|
| 本质 | 正式版游戏的 **Godot + C# 反编译源码**（场景、着色器、音频 bank、本地化都在） | **纯逻辑 headless 模拟器**，照游戏代码逐方法移植，MIT |
| 体量 | 极大（含全部美术/音频资源，需 sparse checkout 才拉得动） | 8 MB 源码，1795 个 .cs 文件 |
| 可直接运行 | 需要正版游戏资源、Godot 4 + .NET 9 环境，跑起来就是完整游戏 | `dotnet build` 即可，不出画面，只有对局结果 |
| 内容完整度 | 100%（它就是游戏本体） | 卡牌/药水/四幕遭遇/事件/遗物基本齐；多人模式与少量内容未移植 |
| 随机数 | 原始实现 | 逐位对齐（顺序模式），可复现真实客户端对局 |
| 中文文本 | ✅ `localization/zhs/*.json`（卡牌、遗物、能力、怪物招式全有） | ❌ 明确不含本地化文本 |
| 适合拿来做什么 | 查"到底怎么写的"、抄文本、抄 UI 资源 | 查"数值是多少"、验证规则、拿真实对局做对拍 |

**结论（也是本项目的做法）**：
- 数值以 `sts2-sim` 为准——它是带注释的干净 C# 代码，卡牌伤害、怪物招式、进阶差异都能直接读到。
- 文本以 `STS2SourceCode` 的 `localization/zhs` 为准——官方中文，卡名、描述、状态说明一键对齐。
- 二者拼起来，正好能得到"忠实还原的数据"，而不需要去碰游戏本体资源。

本仓库不含任何原作美术/音频资源，界面图标用汉字与系统 Emoji。

## 二、当前实现范围

**角色**：开局先选角色。当前**铁甲战士（Ironclad）**、**静默猎手（Silent）**、**故障机器人（Defect）**
与**储君（Regent）**都可以玩。

- 铁甲战士：63 张可用卡（含 3 张基础牌）+ 6 张状态/诅咒，力量/格挡/灼烧流派
- 静默猎手：85 张卡（含 4 张基础牌与衍生牌「小刀」），专属机制为**中毒 / 小刀 / 弃牌 / 奇巧**
  （奇巧牌被弃置时会自动打出）、下回合延时效果。多人限定牌（刃之交响、调合、褪色、包夹、鬼祟）未收录
- 故障机器人：86 张卡（官方 91 张去掉 5 张多人限定牌），专属机制为**充能球**：
  闪电 / 冰霜 / 黑暗 / 等离子 / 玻璃五种球，生成（充能）→ 回合结束被动 → 激发；
  另有**集中**（提高球的数值，可为负）、球栏位、黑暗累伤、玻璃衰减。起始遗物「破损核心」开局送 1 个闪电球
- 储君：86 张卡（官方 91 张去掉 5 张多人限定；2 张远古牌收录为 `special`，不进普通奖励池）
  + 衍生牌「君王之剑」，另加 8 件专属遗物。专属机制为**星愿 / 铸造 / 君王之剑**：
  星愿是第二资源，不随回合重置，部分牌要同时付能量与星愿（牌面右上角紫色角标），
  X 星费会把当前星愿一次花光；「铸造」在没有君王之剑时生成一张到手牌，
  并让所有牌堆里的君王之剑伤害累加；配套能力有群星之子、黑洞、创世纪、封印王座、
  追踪之刃、剑圣、招架、征服者、王之凝视、熔炉等。起始遗物「天赋君权」每场战斗开局给 3 星愿

剩下**亡灵契约师**仍在选人界面标注「数据待移植」——她需要奥斯提召唤物的独立子系统。
角色表在 `src/data/characters.js`，生命/起始遗物/起始牌组/球栏位都按原作填好。

卡池按角色隔离：`Run.poolByRarity()` 只返回当前角色的牌，奖励/商店/随机生成都不会串池。

**第一幕「蔓生之地」完整内容**：
- 17 种普通遭遇（含幼体史莱姆、劫掠者五人组、墨宝三连、雾菇+幻象等组合）
- 3 个精英：旧日雕像、多尼斯异鸟、异蛙寄生虫
- 3 个 Boss：仪式兽、同族、墨影幻灵（进阶 10 双 Boss）
- 15 层分支地图 + 休息处 / 商店 / 宝箱 / 「?」事件（7 个事件）

**系统**：
- 战斗：能量/抽牌/弃牌/消耗、格挡、力量敏捷、易伤虚弱脆弱、临时力量、免费攻击、
  灼烧/伤口/眩晕/黏液、能力牌（恶魔形态、壁垒、腐化、无惧疼痛、黑暗之拥、势不可当…）
- 充能球：生成 / 激发 / 栏位上限（最多 10）、回合结束被动、等离子回合开始供能、
  黑暗累伤、玻璃衰减、集中加减（可为负）、临时集中、种类去重（冷却剂/编译冲击/同步）
- 遗物 24 件（含燃烧之血、金刚杵、弹珠袋、锚、钢笔尖、苦无、手里剑、异蛇之眼…）
- 药水 13 种
- 进阶 0–10：精英增多 / 休息回复减少 / 金币减少 / 药水栏位减少 / 亡者之枷 /
  商店涨价 / 药水掉率下降 / 敌人生命与伤害提升 / 双 Boss
- 存档：localStorage 断点续玩、种子可复现（存档记录角色，续玩不会串味）
- 战斗记录：每次战斗都记流水——出牌、伤害（含格挡吸收）、能力增减、敌人招式、抽牌、死亡，
  按回合分组；战斗中右上角 📜 随时翻看，战利品界面可回看上一场，支持一键复制成纯文本复盘
- **点开即看**：战斗记录里的牌名 / 状态名 / 敌人名 / 遗物名 / 机制词都会高亮，点一下弹出详情
  （卡牌会画出牌面并附升级后文本；状态会带上当时的层数）。战斗界面上点敌人看血量与招式、
  点身上的状态图标看效果、点能量/格挡/生命/金币/回合看规则，点角色面板看自己这条命的所有状态，
  点怪物头顶的意图看意图图例
- **敌人招式可查**：战报里「某敌人 行动：某招式」的招式名可点，弹层给出这招干什么、
  意图类型、当前状态下每次的实际伤害；行尾也会直接带一句简介（如「— 造成 14 点伤害」），
  复制战报时这句也会一起复制。描述由招式实现代码自动还原，新增敌人不用另写文案
- **战利品不丢**：金币/遗物/药水可以当场点选，也可以只选卡牌直接「继续」——
  没领的金币与道具会在继续时自动收下（底部会列出还差哪几项），重复点不会双发
- **商店先看后买**：每件货都直接显示效果摘要与价格；点任意商品弹出详情（卡牌画出完整牌面，
  遗物/药水给完整说明），确认后才扣钱。金币不够时价格标红并显示「还差 N」，
  详情里按钮变灰并说明差额；药水栏满会提前标出来。买完不会把列表弹回顶部

**明确简化**（与原作的差异）：
- 移植了铁甲战士、静默猎手、故障机器人、储君四个角色；亡灵契约师只有选人卡片，没有卡池与专属机制。
  只做第一幕；通关 = 击败第一幕 Boss（可继续扩展数据文件）
- 储君的 5 张多人限定牌（星群/锤击时刻/慷慨/密谋/家教）未收录；2 张远古牌按 `special` 收录但不进奖励池。
  原作「无色牌池」没有移植：随机生成无色牌时用随机技能牌近似；「碎屑」衍生牌用「伤口」近似；
  「下回合从抽牌堆挑 N 张」改为直接取抽牌堆顶 N 张。逐条简化都写在 `cards-regent.js` 的卡上方
- 静默猎手的多人限定牌未收录；「奇巧」按「被弃置时自动打出」实现（单机语义）
- 故障机器人的 5 张多人限定牌（能量涌动/休眠/引火/模仿学习/众志成城）未收录；
  「偏差认知」「四重释放」在原作是**远古稀有度**（不走普通奖励池），这里按稀有牌处理
- 球栏位只在战斗内变动（扩容/模组改造/暴涨），不影响战后
- 「遗传算法」的永久成长写回牌组条目（同一局内跨战斗生效），但换牌/重开即重置
- 事件文本为自写，效果按原作精神简化
- 少数复杂的遗物/卡牌未实现或做了等效简化（如"孙子兵法""壶铃"只做了基础效果）
- 敌人 AI 用"固定循环 + 加权随机"代替原作的完整状态机（数值不变）
- 没有附魔、没有卡牌变形（「压缩」按直接变成「燃料」处理）、没有多人模式

**已对齐的细节**（容易漏、但影响手感的）：
- 首领战「同族」的小兵特性：神官一倒，两名信徒立即消散（原作 `MinionPower`）
- 一名敌人被单张牌打死时，附带的易伤/虚弱只会落在它自己身上，不会"转移"到另一个敌人
- 敌人格挡在其回合开始时清零；玩家格挡在回合开始时清零（除"壁垒"）
- 异蛇之眼的混乱费用在抽到时锁定，不会因重绘而跳动
- 一张牌打死最后一个敌人后，它剩下的"选择牌"之类的效果不再结算，也不会弹出选择面板
  （原作同样如此：战斗已经结束，后续效果无意义）
- 充能球从左往右排，**最左边就是下一个被激发的**；栏位满了再生成，会先激发最左边那个
  （原作的球队列方向与官方文案里的"最右侧"是同一件事，本仓库统一按"最左侧 = 最先激发"来写文案）
- 球的伤害不吃力量/钢笔尖（原作 Unpowered），但仍会被易伤放大、被无实体压成 1
- 冰霜球的格挡不受敏捷加成、也不被脆弱削减（同样是无源数值）
- 能力牌打出后本场不再回到牌堆；虚无牌在回合结束时无论是否保留手牌都会被消耗
- 「回响形态」只复制**能力生效之后**打出的牌——能力牌自己不会被复制（原作的次数在能力结算时才发放）。
  爆发、信号增强、连环拳的"下一张"同理只吃一张，不会因复制而多扣

## 三、运行

```bash
# 需要 Node 16+（只用来起静态服务器）
node tools/serve.mjs        # 然后打开 http://localhost:8081
```

> 注意：**不要用 `python -m http.server`**。Windows 注册表会把 `.js` 映射成 `text/plain`，
> 浏览器会拒绝加载 ES Module，页面会白屏。

### 手机上玩（安卓）

**方式 A：PWA（最省事，推荐先这样用）**
1. 手机和电脑同一局域网，电脑跑 `node tools/serve.mjs`
2. 手机 Chrome 打开 `http://<电脑IP>:8081`
3. 菜单 →「添加到主屏幕」，之后全屏运行、断网也能玩（Service Worker 已缓存全部资源）

**方式 B：打包成 APK（Capacitor）**
```bash
npm i -D @capacitor/cli @capacitor/core @capacitor/android
npx cap init 尖塔之下 com.example.sts2lite --web-dir=.
npx cap add android
npx cap sync
npx cap open android     # 在 Android Studio 里 Build APK
```
不需要任何插件：本项目没有网络请求、没有原生 API，纯静态资源即可。

**方式 C：TWA**（已发布到 https 时用），或直接用 WebView 壳工程加载本地 `index.html`。

> 卡面用 `{Gold}` 变量显示实际数值。类似的还有 `NEUTRON_AEGIS` / `PARRY` / `FURNACE` 等：
> 它们的 `GeneratedCardSpec` 全为 0，真正层数来自 `GeneratedPowerEffects` 映射，不能只读 Spec。

## 六、自测

```bash
node tools/smoke.mjs SEED 0     # 引擎层跑一整局（不启动浏览器）
node tools/regress.mjs          # 边界回归：带选择效果的牌补刀、面板挂起时战斗结束
node tools/e2e-full.mjs         # 需要先在 8081 端口起服务；跑完整幕并检查 JS 报错
node tools/e2e-save.mjs         # 中途存档 → 重载 → 继续打，校验状态一致
node tools/e2e-inspect.mjs      # 点开关键词/状态/敌人/能量，逐个校验详情弹层
node tools/e2e-silent.mjs       # 静默猎手：选人、小刀、中毒、战报
node tools/e2e-defect.mjs       # 故障机器人：选人、充能球、激发、球详情、战报
node tools/e2e-regent.mjs       # 储君：星愿 HUD、星费牌、铸造、词条、战报
node tools/regent-verify.mjs    # 储君机制对拍 33 项（纯 Node，不需要浏览器）

```

端到端脚本默认连 8081 端口，也支持 `PORT=8082 node tools/serve.mjs` +
`PORT=8082 node tools/e2e-full.mjs` 换端口（多工作树并行时很方便）。

`balance.mjs` 里的 AI 只是一个"会按场面格挡、能选牌、会用遗物/药水"的新手模型，
不代表人类上限。当前抽样（asc 0）大致是：铁甲 60 局**胜率 20%**，38 局能走到首领，
平均在首领处剩余 44 血；故障机器人 30 局**胜率 33%**（26 局撑到首领，首领处约 40 血）；
储君 20 局**胜率 20%**、平均 14.8 层、首领处 36.7 血
——也就是"数据还原后第一幕就是硬仗"，而不是数值被改软了。
想更贴近原作手感，可以在这个脚本里把 AI 的策略改强再对比。
